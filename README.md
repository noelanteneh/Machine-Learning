# Machine Learning & Data Science

A collection of my hands-on learning, exercises, and projects in Data Science and Machine Learning using Python.

## Technologies

- Python
- NumPy & Pandas
- Matplotlib & Seaborn
- Scikit-learn
- SQL & SQLite
- Jupyter Notebook

## Topics & Practical Work

This repository is organized into different learning areas. Each topic folder contains relevant Jupyter notebooks, exercises, and practical projects demonstrating the concepts in action.

- Python Fundamentals
- NumPy & Pandas
- Data Visualization and Exploratory Data Analysis
- Linear and Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Trees and Random Forest
- Feature Selection

## Featured Projects

- **ChatGPT Prompt Analysis:** Exploring prompt patterns, text characteristics, and response readability.
- **Zomato Data Analysis:** Restaurant data exploration using SQL, Python, text analysis, and geographical visualization.
- **FIFA 23 Analysis:** Exploring player attributes, distributions, and relationships through data visualization.

## How to Explore

Navigate through the topic folders to discover the notebooks and practical work inside each section. Open any `.ipynb` file directly on GitHub to explore the code, explanations, visualizations, and results.
